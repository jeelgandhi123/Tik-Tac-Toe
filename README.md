Tic-Tac-Toe is a fun and interactive web-based game built using HTML, CSS, and JavaScript. It supports two players who take alternate turns marking X and O on a clean 3x3 grid. The game intelligently detects winning combinations after each move and announces the winner or a draw when appropriate. With a single click on the “New Game” button, players can quickly reset the board and enjoy unlimited rounds. The sleek, responsive UI ensures a smooth and engaging experience across all devices.
